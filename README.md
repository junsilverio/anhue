# ANHUE TECH Engineering Services — Landing Page

A modern corporate landing page built with **Angular**, featuring a dark navy + orange theme, glassmorphism cards, sticky navigation and a fully responsive layout.

## Pages

1. Landing Page (`/`)
2. About Us (`/about`)
3. Mission, Vision & Values (`/mission-vision-values`)
4. Leadership & Team (`/leadership`)
5. Services Overview (`/services`)
6. Mechanical & Electrical (`/services/mechanical-electrical`)
7. Construction & Renovation (`/services/construction-renovation`)
8. Structural & Civil Works (`/services/structural-civil`)
9. Water System Services (`/services/water-systems`)
10. Security & Communication Systems (`/services/security-communication`)
11. Maintenance Services (`/services/maintenance`)
12. Projects Portfolio (`/projects`)
13. Project Details (`/projects/:slug`)
14. Clients & Partners (`/clients`)
15. Contact / Request a Quote (`/contact`)

## Design System

- 🌙 Dark Navy + Orange ANHUE TECH branding (CSS custom properties in `src/styles.scss`)
- ✨ Glassmorphism premium cards (`.glass-card`)
- 📌 Sticky navigation with dropdown menus
- 🧩 Reusable components: header, footer, page hero, CTA banner, SVG icon set
- 📐 Consistent spacing, typography and grid utilities
- 🎞️ Subtle fade-up animations
- 🖥️ Desktop-first responsive layout down to mobile

## Development

```bash
npm install
npm start        # dev server on http://localhost:4200
npm run build    # production build to dist/
```
